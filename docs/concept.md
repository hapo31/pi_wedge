# コンセプト

LANクライアントとAIエージェントがSTL/STEPをアップロードし、Piで非同期にスライスしてUUIDで成果物を参照する。Webで確認後、明示的にA1 miniへ転送・印刷する。運用時にクラウドの認証・ストレージ・スライスサービスを必要としない。ソフトウェア導入時のダウンロードは別。
中心の用途は「AIへモデル作成を依頼し、AIから届いたURLをスマホで開いてプレビューし、確認して印刷開始する」。スマホはトークン入力や管理画面を経由せず、信頼するLANから直接利用する。モデル投入・スライス・管理APIはAIがBearer認証で使用する。

対象はPi 5 8GB、64bit Pi OS、単一A1 mini、0.4mmノズル、PLAを初期設定とする。機器の型番/ノズル/材料一致は管理者が確認。
ブラウザではスライス履歴、プレビュー、印刷開始を利用する。アップロード/スライスはSwagger/APIから操作する。MCPはAPIとプレビューの使い方を案内し、操作は実行しない。

スコープ外: CAD編集、再スライスUI、MCPによる操作実行、クラウド印刷、複数プリンター、スプール在庫、印刷履歴の高度な監視。
