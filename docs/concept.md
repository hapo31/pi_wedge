# コンセプト

LANクライアントとAIエージェントがSTL/STEPをアップロードし、Piで非同期にスライスしてUUIDで成果物を参照する。Webで確認後、明示的にA1 miniへ転送・印刷する。運用時にクラウドの認証・ストレージ・スライスサービスを必要としない。ソフトウェア導入時のダウンロードは別。
対象はPi 5 8GB、64bit Pi OS、単一A1 mini、0.4mmノズル、PLAを初期設定とする。機器の型番/ノズル/材料一致は管理者が確認。
スコープ外: CAD編集、再スライスUI、MCP、クラウド、複数プリンター、スプール在庫、印刷履歴の高度な監視。UIはプレビューと印刷開始専用。アップロード/スライスはSwagger/APIから操作。
